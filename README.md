### Описание проекта

#### Задача

Приложение создано для отслеживания привычек и прогресса их выполнения.  
Оно помогает пользователю формировать полезные привычки, видеть динамику выполнения и мотивировать себя на регулярность.

#### Целевая аудитория

- Люди, которые хотят улучшить свою продуктивность
- Пользователи, формирующие здоровые привычки (спорт, питание, сон)

#### Возможности

- Регистрация и авторизация (через email или Google-аккаунт).
- Добавление и удаление привычек
- Отмечание дней выполнения привычек в календаре
- Автоматический подсчёт прогресса и статистики
- Визуализация прогресса с помощью диаграмм
- Поддержка мобильной версии

#### Общие требования к функциональности

- Веб-приложение доступно в интернете
- Данные пользователей хранятся удалённо (Firebase)
- Данные разных аккаунтов полностью разделены

### Технические требования

#### Линтинг

- Настроен ESLint и Prettier
- Проверка линтинга выполняется через CI/CD

#### CI/CD

- Настроен GitLab CI для автоматической сборки, проверки и деплоя
- Включены:
  - Линтинг (ESLint, Prettier).
  - Проверка типов TypeScript.  
    (Unit-тесты (Vitest) - написала только один для самого теста - не считается)
- Деплой выполняется автоматически после успешной сборки

#### Маршруты

Приложение содержит минимум три маршрута:

1. `/` — список привычек
2. `/habits/:id` — страница отдельной привычки с календарём и прогрессом (динамический роут)
3. `/auth` — страница логина/регистрации
4.  `/dashboaed` - статистика
